# 🐔 Poultry-Farm | مزرعتي

تطبيق ويب تقدمي (PWA) بدون خادم (Serverless & Offline-First) لإدارة مزارع الدواجن والسمان وتتبع الدفعات والمهام والتذكيرات والمصروفات والأرباح.

---

## ✨ المميزات الرئيسية

- **📱 تطبيق ويب تقدمي (PWA)**:
  - يعمل بدون اتصال بالإنترنت تماماً (Offline-First).
  - يمكن تثبيته على أجهزة Android و iOS عبر متصفح الهاتف ("Add to Home Screen").
  - واجهة تطبيق أصلية بشاشة كاملة بدون شريط عنوان المتصفح.

- **💾 قاعدة بيانات محلية (IndexedDB + Dexie.js)**:
  - جميع البيانات تُحفظ محلياً على جهاز المستخدم.
  - لا تتطلب خادماً أو اشتراكاً سحابياً مدفوعاً.
  - دعم ترقية المخطط (Schema Migration) من الإصدار 1 إلى الإصدار 2.

- **🐣 إدارة الدفعات (Batches)**:
  - تسجيل دفعات الطيور والسمان والدواجن.
  - متابعة أعداد الطيور وحساب العمر بالأيام تلقائياً.
  - توثيق سعر شراء الدفعة الأولي.
  - دورة حياة الدفعة (نشطة، مبيعة، مغلقة) مع تسجيل تاريخ ووقت البيع والإغلاق.

- **⏰ إدارة المهام والتذكيرات الميدانية**:
  - جدولة التطعيمات، الأدوية، تغيير العليقة، والأوزان.
  - تذكيرات داخل التطبيق للمهام المستحقة اليوم والمتأخرة.
  - توثيق تاريخ ووقت إنجاز كل مهمة وتأجيل المهام.

- **📊 النظام المالي ومتابعة المصروفات**:
  - تسجيل بنود المصروفات (أعلاف، أدوية، تحصينات، فيتامينات، معدات، أخرى) بالتاريخ والوقت.
  - تصفية المصروفات حسب البند.
  - ملخص مالي فوري: سعر الشراء + المصروفات الإضافية = إجمالي الاستثمار.
  - حساب صافي الربح / الخسارة تلقائياً بمجرد تسجيل إيراد البيع.

- **💾 النسخ الاحتياطي والاستعادة**:
  - تصدير كامل بيانات المزرعة إلى ملف `JSON`.
  - استعادة البيانات مع التحقق من صحة الملف وطلب التأكيد قبل الاستبدال.

## 🚀 التشغيل محلياً

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build

# معاينة النسخة الإنتاجية
npm run preview
```

## 🌐 النشر على GitHub Pages

يحتوي المشروع على سير عمل آلي عبر **GitHub Actions** (`.github/workflows/deploy.yml`):
- عند الدفع إلى فرع `main`، يتم بناء التطبيق ونشره تلقائياً على GitHub Pages.
- للتمكن من تشغيل GitHub Pages، يجب أن يكون المستودع عاماً (**Public**) على خطة GitHub المجانية، أو مستودعاً خاصاً بحساب GitHub Pro.
